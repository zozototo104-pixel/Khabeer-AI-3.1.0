# الخبير الذكي المؤسسي — الإصدار 3.1.0

منصة عربية لإدارة الاجتماعات تجمع بين الحوار الصوتي المباشر، لوحة خبراء متعددة التخصصات، ذاكرة المؤسسة، استرجاع اللوائح، هوية المتحدث العصبية، وسجل قابل للتدقيق للقرارات والتوصيات والمهام والمخاطر والمخالفات والنتائج المهنية.

## ما الذي يميز هذا الإصدار؟

- نموذج هوية متحدث عصبي حقيقي `3D-Speaker ERes2Net` يعمل محلياً على الخادم عبر `sherpa-onnx-node` ويولّد متجهات من 512 بعداً.
- قرار المتحدث النهائي يعتمد على إجماع عدة نوافذ صوتية عالية الجودة مع استبعاد النافذة الشاذة بدلاً من الاعتماد على أعلى نافذة طاقة فقط.
- بوابة مقاطعة تكيفية تمنع صدى صوت الخبير من الوصول إلى VAD أثناء النطق، مع pre-roll قصير للمقاطعات الحقيقية ومخزن jitter تكيفي لمنع التقطع.
- رفع PDF وDOCX وXLSX وCSV وTXT وMD وJSON يحفظ الملف الأصلي كاملاً والنص المفهرس في معاملة واحدة، مع SHA-256 وتنزيل الأصل لاحقاً.
- تحقق SHA-256 من النموذج عند التشغيل؛ عند تعذره يفشل التعرف بالاسم بأمان ولا يخمّن هوية الحاضر.
- حفظ دائم لملفات المتحدثين مع رقم إصدار النموذج، ومنع مقارنة بصمات صادرة من نماذج مختلفة.
- نسبة كل مداخلة صوتية إلى المتحدث الموثق مع درجة الثقة ورقم الدور، مع رفض التطابق الملتبس.
- Gemini 3.1 Flash Live للحوار الصوتي منخفض الكمون، والمقاطعة الطبيعية، والنص الحي، واستدعاء أدوات الاجتماع.
- تسجيل فوري للقرار والتوصية والتكليف والخطر، ومنع التكرار، وسجل زمني `meeting_events` قابل للتدقيق.
- تنفيذ المخرجات المسندة صراحة إلى الخبير (تقرير، خطة، سياسة، قائمة تدقيق، إجراء، محضر أو مسودة قرار) وحفظها كمهمة.
- إنشاء محضر رسمي من النص المسجل مع إبقاء عناصر السجل الرسمية مرجعاً نهائياً؛ لا يستطيع النموذج إضافة قرار أو مسؤول أو موعد غير مسجل.
- عزل كامل لبيانات المؤسسات؛ لا تُرجع قاعدة المعرفة مستندات مؤسسة أخرى عند غياب مستندات المؤسسة الحالية.
- تقسيم وحدات الواجهة وتحميلها عند الحاجة لتقليل زمن الفتح، مع تحميل نموذج الصوت مرة واحدة فقط في ذاكرة الخادم.
- كتالوج يضم 29 خبيراً في الحوكمة والرقابة والاستراتيجية والمالية والقانون والهندسة والتقنية والسلامة؛ يمكن اختيار خبير قائد وثلاثة مراجعين.
- محرك مخاطر 5×5 يحفظ الاحتمال والأثر والدرجة المتأصلة والمتبقية والضوابط والمالك والموعد.
- دورة حياة مستقلة للمخالفة: `SUSPECTED → UNDER_REVIEW → CONFIRMED/DISMISSED → REMEDIATED`، ولا يستطيع النموذج تأكيدها بنفسه.
- سجل نتائج منفصل للثغرات والملاحظات التي لا تستوفي دليل المخالفة.
- بوابة صوت ثنائية الاتجاه لـ Twilio وWhatsApp Business Calling المؤهل، بجلسات موقعة وموافقة تسجيل صريحة وتحويل صوت حي إلى Gemini.

## المتطلبات والتشغيل

- Node.js 22 أو أحدث وأقل من 25 (Linux x64 مدعوم بالحزمة الحالية).
- PostgreSQL.
- Firebase Auth وملف إعداد صالح.
- مفتاح Gemini API لديه صلاحية Live API.

```bash
cp .env.example .env.local
npm ci
npm run db:migrate
npm run speaker:verify-model
npm run dev
```

فحوص الإصدار:

```bash
npm run test:unit
npm run lint
npm run build
```

## النشر

المشروع جاهز للبناء داخل حاوية عبر `Dockerfile`. شغّل ترحيلات PostgreSQL قبل بدء النسخة الجديدة، واستخدم `/api/health` لفحص الحياة و`/api/ready` لفحص قاعدة البيانات والنموذج العصبي. راجع [DEPLOYMENT_AR.md](./DEPLOYMENT_AR.md) لقائمة الأسرار وخطوات النشر الآمن.

## إعداد AI Studio

افتح المشروع كاملاً بعد فك الضغط أو ارفعه إلى مستودع GitHub ثم استخدم Import من Google AI Studio. لا ترفع ملف النموذج وحده؛ النموذج جزء من الخادم ويحتاج الكود والاعتمادات وقاعدة البيانات.

أضف الأسرار والمتغيرات من `.env.example`. القيمة الافتراضية للبث هي `gemini-3.1-flash-live-preview` ويمكن تجاوزها عبر `GEMINI_LIVE_MODEL`.

## فحص نموذج الصوت

راجع `models/README.md`. نقطة الصحة التالية تتطلب حساباً مصادقاً:

```text
GET /api/speaker/model-health
```

يجب أن تعيد `neuralAvailable: true` و`mode: "NEURAL"` و`embeddingDimension: 512`.

## الخصوصية والاعتماد

بصمة الصوت والنسخ النصي بيانات حساسة. يلزم HTTPS، وضبط وصول قاعدة البيانات، وسياسة احتفاظ وموافقة الحاضرين قبل التسجيل. التعرف الصوتي يساعد في نسبة المداخلات لكنه ليس إثبات هوية قانونياً منفرداً. كل مخرج يولده الخبير يبقى «مسودة للمراجعة والاعتماد» حتى يراجعه صاحب الصلاحية.

## الاتصالات الخارجية

بعد نشر التطبيق على HTTPS، اضبط `PUBLIC_BASE_URL` و`EXPERT_CHANNEL_SECRET`. من إعدادات الاجتماع وافق على التسجيل وأنشئ رابط Webhook مؤقتاً، ثم ضعه في إعداد Voice Webhook لدى Twilio/WhatsApp Business Calling. الرابط صالح 15 دقيقة ومقيد بالمؤسسة والاجتماع ولوحة الخبراء.

لا تسمح منصة Messenger رسمياً لبوت بالانضمام إلى مكالمة صوتية شخصية قائمة. لذلك يعرض النظام هذه القناة كغير مدعومة، ويتيح بدلاً منها «جسر مكبر الصوت» داخل اجتماع المنصة. يجب التحقق من أهلية WhatsApp Business Calling وشروط استخدام المساعدين الآليين مع المزود والمنصة قبل التشغيل التجاري.
