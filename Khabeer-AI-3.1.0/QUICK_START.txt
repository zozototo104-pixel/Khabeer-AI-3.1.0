الخبير الذكي المؤسسي — الإصدار 3.0.2

ملخص سريع:
- المشروع يعمل على Node.js 22 أو أحدث (أقل من 25)
- يحتاج PostgreSQL + Firebase Service Account + GEMINI_API_KEY للتشغيل الكامل
- في حالة عدم توفر هذه الخدمات، يعمل المشروع في وضع mock (واجهة فقط دون حفظ بيانات)

التشغيل السريع (جهاز حقيقي):
  1. فك الضغط: unzip Smart-AI-FINAL.zip
  2. cd Smart-AI-main
  3. cp .env.example .env   (ثم املأ القيم)
  4. npm ci
  5. npm run db:migrate     (يحتاج PostgreSQL يعمل)
  6. npm run dev
  7. افتح http://localhost:3000

التشغيل في وضع التطوير دون قاعدة بيانات:
  - استخدم السكريبت run_server.sh (يُلغي DATABASE_URL ويسمح بوضع mock)

الملفات المهمة:
- README.md          — وثائق المشروع بالعربية
- DEPLOYMENT_AR.md   — دليل النشر
- server.ts          — نقطة الدخول للخادم
- index.html         — نقطة الدخول للواجهة
- .env.example       — نموذج الإعدادات
- migrations/        — سكريبتات قاعدة البيانات
- models/            — نموذج التعرف على الصوت (3D-Speaker)
- WORKLOG.md         — سجل ما تم في بيئة التشغيل
