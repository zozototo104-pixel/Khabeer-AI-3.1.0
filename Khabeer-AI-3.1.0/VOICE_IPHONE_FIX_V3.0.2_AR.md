# إصلاح بدء الحوار الصوتي على iPhone — الإصدار 3.0.2

يعالج هذا التحديث حالة منح إذن الميكروفون وبقاء شاشة الحوار في وضع التحميل دون بدء الجلسة.

## ما تم إصلاحه

- فتح واستئناف محرك Web Audio داخل ضغطة المستخدم كما يتطلب iOS.
- دعم معدل الالتقاط الفعلي في iPhone، مع تحويل الصوت إلى PCM ‏16 kHz قبل الإرسال.
- إبقاء معالج الميكروفون نشطًا على iOS دون إعادة صوت الميكروفون إلى السماعة.
- انتظار تأكيد جاهزية جلسة Gemini Live قبل إرسال الصوت.
- تحديث رمز تسجيل الدخول قبل فتح الاتصال الصوتي.
- عرض مراحل الاتصال بدل مؤشر تحميل صامت.
- إيقاف المحاولة برسالة واضحة بعد 90 ثانية بدل الانتظار إلى ما لا نهاية.
- تحسين تنظيف الميكروفون ومحركات الصوت والاتصال عند الفشل أو الإغلاق.

## التثبيت من GitHub Codespaces

ارفع الملف `smart-expert-iphone-voice-fix-v3.0.2.zip` إلى جذر المستودع، ثم نفّذ الأوامر التالية كل أمر على حدة:

```bash
unzip -o smart-expert-iphone-voice-fix-v3.0.2.zip
git add -- package.json package-lock.json server.ts src/components/VoiceChat.tsx VOICE_IPHONE_FIX_V3.0.2_AR.md
git commit -m "fix iPhone live voice startup"
git push
```

سيبدأ Render النشر التلقائي بعد نجاح `git push`.

## التحقق بعد النشر

1. انتظر حتى تظهر حالة `Live` في Render للالتزام الجديد.
2. أغلق تبويب البرنامج في Chrome وافتحه مجددًا.
3. اضغط **بدء الحوار الصوتي** مرة واحدة واسمح بالميكروفون.
4. ستظهر مراحل مثل: فتح الاتصال، تجهيز الجلسة، ثم **متصل — الخبير يستمع الآن**.
5. لأن خدمة Render المجانية تدخل وضع السكون، قد تستغرق أول محاولة بعد الخمول قرابة 50 ثانية أو أكثر؛ المحاولات التالية تكون أسرع.

إذا استمر ظهور الواجهة القديمة، أغلق التطبيق المثبت وافتح الرابط في Chrome مجددًا، ثم أعد تثبيت التطبيق بعد ظهور الإصدار الجديد.
